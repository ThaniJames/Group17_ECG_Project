# D7043E — Edge-Ready ECG Classification (MIT-BIH → MAX78002)

Four-class heartbeat classification (N / S / V / F) with a compact 1D CNN designed for the
Analog Devices MAX78002 Edge-AI accelerator, following CRISP-DM.

## Setup & Start
# This will download & Process the data

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```
